# 1.4.1 — 🎯 C Landmark Drill

### What you are learning

Find **C** using the **2-black-key pattern**.

The keyboard repeats this pattern:

**2 black keys → C D E → 3 black keys → F G A B → 2 black keys → C...**

So:

> **C is immediately to the LEFT of the group of 2 black keys.**

**C → D → E → F → G → A → B → C**

**F G A B**

**C D E**

**F → G → A → B → C → D → E → F**
