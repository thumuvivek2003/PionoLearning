# 🎼 LEVEL 7 — 🎹 PLAYING PATTERNS

## 🥁 Bucket 7.6 — Left-Hand Accompaniment

### 🎯 Overall Goal

By the end of this bucket, your left hand should be able to:

**Root → Bass → Chord → Pattern → Progression → Song accompaniment**

Use **C major** initially because it has no black keys:

* C major chord = **C–E–G**
* F major chord = **F–A–C**
* G major chord = **G–B–D**

Start around **60 BPM**. Increase only when you can play cleanly.

---

## 🎹 7.6.1 — Root Notes

### 🎯 Objective

Learn to use the left hand as the **bass foundation**.

### Practice

Use these roots:

**C → F → G → C**

Play only one note at a time.

```text
C     | F     | G     | C
1     | 1     | 1     | 1
```

Start with **4 beats per note**:

```text
C — — —
F — — —
G — — —
C — — —
```

### 🖐️ Fingering

Use your **5th finger (pinky)** for the root notes initially.

```text
C = 5
F = 5
G = 5
```

Don't worry about moving your whole hand perfectly yet. Focus on landing accurately.

### 🔁 Practice Levels

**Level 1:** C only × 10 repetitions
**Level 2:** C → F → C
**Level 3:** C → F → G → C
**Level 4:** Change chords every 2 beats
**Level 5:** Change chords every 1 beat

### ✅ You are ready to move on when

You can play:

**C → F → G → C**

without looking constantly at your left hand.

---

# 🎹 7.6.2 — Root–Chord Pattern

### 🎯 Objective

Learn the basic idea of:

**Bass → Chord → Bass → Chord**

For C major:

```text
C → C-E-G → C → C-E-G
```

For F:

```text
F → F-A-C → F → F-A-C
```

For G:

```text
G → G-B-D → G → G-B-D
```

### 🥁 Count

Use:

```text
1     2     3     4
Bass  Chord Bass  Chord
```

So:

```text
C       C-E-G       C       C-E-G
1       2           3       4
```

### 🎹 Practice

Start:

```text
C → C chord × 4
F → F chord × 4
G → G chord × 4
C → C chord × 4
```

Then combine:

```text
C       C-E-G       C       C-E-G
F       F-A-C       F       F-A-C
G       G-B-D       G       G-B-D
C       C-E-G       C       C-E-G
```

### 🎯 Important

Don't rush the chord after the bass.

Think:

> **BASS — CHORD — BASS — CHORD**

This teaches your brain to separate the bass note from the harmony.

---

# 🎹 7.6.3 — Octave Bass

### 🎯 Objective

Make your accompaniment sound **bigger and deeper** by using the same root in different octaves.

For C:

```text
Low C → Higher C
```

For F:

```text
Low F → Higher F
```

For G:

```text
Low G → Higher G
```

### 🥁 Basic Pattern

Count:

```text
1   2   3   4
C       C
```

Play:

```text
Low C → High C
Low F → High F
Low G → High G
Low C → High C
```

### 🔁 Practice

First practice slowly:

```text
C(low) → C(high)
F(low) → F(high)
G(low) → G(high)
C(low) → C(high)
```

Then:

```text
Low C → High C → Low C → High C
```

### 🎯 Goal

Develop the ability to **jump between bass positions without losing the beat**.

This becomes very useful later for pop, worship, cinematic and ballad accompaniment.

---

# 🎹 7.6.4 — Bass + Chord

### 🎯 Objective

Combine a **strong bass note** with the full chord.

Pattern:

```text
BASS → CHORD
```

For C:

```text
C → C-E-G
```

For F:

```text
F → F-A-C
```

For G:

```text
G → G-B-D
```

### 🥁 Practice

Count:

```text
1   2   3   4
B   C   -   -
```

Example:

```text
C       C-E-G       —       —
```

Then make it more rhythmic:

```text
1   2   3   4
C   CH  C   CH
```

### 🔥 Challenge

Try:

```text
C → C chord → C → C chord
F → F chord → F → F chord
G → G chord → G → G chord
C → C chord → C → C chord
```

### 🎯 Musical Goal

You should start hearing:

**Bass = foundation**

**Chord = harmony**

Together:

**Bass + harmony = accompaniment**

---

# 🎹 7.6.5 — Waltz Pattern

### 🎯 Objective

Learn the classic **3/4 accompaniment**.

The pattern is:

```text
BASS → CHORD → CHORD
```

Count:

```text
1   2   3
B   C   C
```

For C:

```text
C       C-E-G       C-E-G
1       2           3
```

For F:

```text
F       F-A-C       F-A-C
1       2           3
```

For G:

```text
G       G-B-D       G-B-D
1       2           3
```

### 🥁 Practice

Say aloud:

> **ONE — TWO — THREE**

while playing:

```text
Bass — Chord — Chord
```

### 🔁 Progression

```text
C | C | F | F |
G | G | C | C |
```

### 🎯 Important

The **first beat should feel stronger**.

Think:

> **ONE-two-three | ONE-two-three**

That's what gives the pattern its waltz feeling.

---

# 🎹 7.6.6 — Pop Pattern

### 🎯 Objective

Develop a repeating accompaniment pattern that feels more like modern music.

Start with:

```text
Bass → Chord → Chord → Chord
```

Count:

```text
1   2   3   4
B   C   C   C
```

Example:

```text
C     C-E-G     C-E-G     C-E-G
1       2         3         4
```

### 🔥 Next Level

Try:

```text
Bass → Chord → Bass → Chord
```

```text
1   2   3   4
B   C   B   C
```

Then introduce octave bass:

```text
Low Bass → Chord → High Bass → Chord
```

### 🎯 Goal

Your left hand should become a **repeating rhythmic machine**.

Don't stop between repetitions.

For example:

```text
C  CH  C  CH | C  CH  C  CH
F  CH  F  CH | F  CH  F  CH
G  CH  G  CH | G  CH  G  CH
C  CH  C  CH | C  CH  C  CH
```

---

# 🎹 7.6.7 — Broken-Chord Accompaniment

### 🎯 Objective

Instead of playing the entire chord simultaneously, break it into individual notes.

C major:

```text
C – E – G – E
```

F major:

```text
F – A – C – A
```

G major:

```text
G – B – D – B
```

### 🥁 Count

```text
1   2   3   4
C   E   G   E
```

So:

```text
C-E-G-E
F-A-C-A
G-B-D-B
C-E-G-E
```

### 🔁 Practice Progression

```text
C-E-G-E
F-A-C-A
G-B-D-B
C-E-G-E
```

Start at **50–60 BPM**.

### 🎯 Focus

Don't treat these as four unrelated notes.

Think:

> **C chord → broken into pieces**

That mental connection is very important.

### 🔥 Challenge

Try different directions:

```text
1–3–5–3
1–5–3–5
1–3–5–8
8–5–3–1
```

This will connect beautifully with your **7.3 Arpeggios** work.

# 🎹 7.6.8 — Chord Progression Accompaniment

### 🎯 Objective

Now combine everything you've learned.

Use:

```text
C → F → G → C
```

This is your main training progression.

---

### 🥉 Stage 1 — Root Only

```text
C | F | G | C
```

Play one root per measure.

---

### 🥈 Stage 2 — Root + Chord

```text
C → Chord
F → Chord
G → Chord
C → Chord
```

---

### 🥈 Stage 3 — Waltz

```text
C | C-E-G | C-E-G
F | F-A-C | F-A-C
G | G-B-D | G-B-D
C | C-E-G | C-E-G
```

Remember:

```text
1   2   3
B   C   C
```

---

### 🥇 Stage 4 — Pop

```text
B C B C | B C B C
```

Apply it to:

```text
C → F → G → C
```

---

### 🥇 Stage 5 — Broken Chords

```text
C-E-G-E
F-A-C-A
G-B-D-B
C-E-G-E
```

# 🎯 Your Complete 7.6 Practice Routine

I recommend doing this **every day for about 30 minutes**:

| Time  | Practice                      |
| ----- | ----------------------------- |
| 3 min | Finger warm-up + locate C/F/G |
| 4 min | 7.6.1 Root Notes              |
| 4 min | 7.6.2 Root–Chord              |
| 4 min | 7.6.3 Octave Bass             |
| 4 min | 7.6.4 Bass + Chord            |
| 4 min | 7.6.5 Waltz                   |
| 3 min | 7.6.6 Pop Pattern             |
| 2 min | 7.6.7 Broken Chords           |
| 2 min | 7.6.8 C–F–G–C progression     |

### 🎹 Your progression ladder

Don't try to master everything simultaneously. Progress like this:

```text
7.6.1 Root Notes
       ↓
7.6.2 Root → Chord
       ↓
7.6.3 Octave Bass
       ↓
7.6.4 Bass + Chord
       ↓
7.6.5 Waltz
       ↓
7.6.6 Pop
       ↓
7.6.7 Broken Chords
       ↓
7.6.8 Full Progression
       ↓
🎵 Real Song Accompaniment
```

### ⭐ Most important rule for your 45-day contest preparation

**Rhythm > Speed.**

Don't play these patterns fast with mistakes. Start around **50–60 BPM**, and only increase the metronome when you can play the pattern **continuously for 2–3 minutes without stopping or losing the beat**.

Your ultimate target for Bucket 7.6 is:

> **Left hand keeps the rhythm automatically while your right hand plays the melody.**

That's the point where your left hand stops feeling like a separate exercise and starts becoming a true **accompaniment engine**. 🎹🔥
