# 1.2.1 — 2-Black-Key Pattern

### 🎯 Objective

Recognize every group of **2 black keys** immediately.

### Step 1 — Find the pattern

Look at your keyboard:

```text
  ▮ ▮       ▮ ▮       ▮ ▮
  C# D#     F# G# A#   C# D#
```

Ignore the note names initially.

Just observe:

```text
▮ ▮     ▮ ▮     ▮ ▮     ▮ ▮
```

### Step 2 — Say it

Point to every pair and say:

> "Two black keys."

Do this from left to right.

### Step 3 — Random recognition

Point randomly:

```text
Pair 1 → 2 black keys
Pair 2 → 2 black keys
Pair 3 → 2 black keys
...
```

### 🎯 Target

You should recognize the **2-key landmark without counting individual keys**.

# 1.2.12 — Flat Names

Now learn the alternate names.

The same five black keys can also be called:

```text
C# = Db
D# = Eb

F# = Gb
G# = Ab
A# = Bb
```

So:

```text
BLACK KEY

C# / Db
D# / Eb

F# / Gb
G# / Ab
A# / Bb
```

### Important concept

This is **one physical key with two names**.

For example:

```text
      ▮
     / \
   C#   Db
```

It is **not two different piano keys**.

It is one physical key that can have two note names depending on musical context.

### Practice

Play a black key and say both names:

```text
C# → Db
D# → Eb
F# → Gb
G# → Ab
A# → Bb
```

Then reverse:

```text
Db → C#
Eb → D#
Gb → F#
Ab → G#
Bb → A#
```
