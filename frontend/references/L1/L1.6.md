# 1.6.1 — 🎯 Same Note Distance

### What you're learning

You already know that the same note appears repeatedly across the keyboard:

```text
C     C     C     C
|-----|-----|-----|
```

Your job is to recognize the **distance between identical notes**.

For example:

```text
C → C
D → D
E → E
F → F
```

The important idea is:

> **Same note = same geographical position inside another octave.**

---

## 🟢 Practice Session A — Find Two Same Notes

Pick one note.

Example:

```text
C
```

Find:

```text
C → C
```

Then:

```text
D → D
E → E
F → F
G → G
A → A
B → B
```

Do this across different parts of the keyboard.

### Goal

Don't think:

> "Let me count all the keys."

Instead think:

> "I see C → I know where the next C lives."

---

## 🟢 Practice Session B — Random Same Note

Ask yourself:

```text
Find C and another C.
Find F and another F.
Find A and another A.
Find D and another D.
```

Then reverse it:

```text
Start at C → find another C
Start at G → find another G
Start at E → find another E
```

### Target

You should become comfortable jumping between octaves.

---

## 🟢 Practice Session C — Distance Direction

Now introduce direction.

Start:

```text
C
```

Then find another C:

```text
C → C
```

Do:

```text
C → higher C
C → lower C
```

Then:

```text
E → higher E
E → lower E
G → higher G
G → lower G
```

This develops **left/right spatial mapping**.

### 🎯 Mastery

You can look at a C and immediately locate another C without consciously searching.

# 1.6.5 — 🧠 White-Key Interval Awareness

Now we combine everything.

You're no longer thinking only:

> "Move 2 keys."

You're beginning to recognize **interval shapes**.

For example:

```text
2nd:
C → D

3rd:
C → E

4th:
C → F

5th:
C → G
```

This becomes extremely important later when you learn chords, scales, melodies and intervals.

---

## Your visual map

```text
C  D  E  F  G  A  B
|--|--|--|--|--|--|

C → D = 2nd
C → E = 3rd
C → F = 4th
C → G = 5th
```

For this bucket, don't worry about advanced interval theory yet.

Your goal is simply:

> **See the spatial distance.**
