**5th line A**

**Middle C**

# 🎯 6.3.9 — Ascending Bass Notes

Now we teach your brain to understand **pitch movement**.

If you move upward on the staff:

> **G → A → B → C → D**

the pitch goes higher.

Remember:

**line → space → line → space**

For example:

```text
G  = line
A  = space
B  = line
C  = space
D  = line
```

Notice the pattern.

### Practice

Start from G:

> G → A → B → C → D → E → F → G

Then:

> A → B → C → D → E

Then:

> B → C → D → E → F

### Keyboard connection

As you read upward, your hand should understand:

> **Move toward higher-pitched keys.**

### 🎯 Goal

Don't treat every note as an isolated object.

Start seeing **movement**.
