# 🥁 LEVEL 3 — RHYTHM & TIMING

## 🪣 Bucket 3.6 — Rhythm Accuracy

### 🎯 Practice Setup

Before every session:

1. Choose **one comfortable keyboard key**, preferably middle C.
2. Set your metronome to **60 BPM**.
3. Use a **single finger** initially.
4. Do not worry about pitch — we're training **timing**.
5. Count aloud whenever possible.
6. Listen carefully to whether your note is **before, exactly on, or after** the beat.

---

# 3.6.1 — Same Note, Different Rhythms

### 🎯 Goal

Learn that **the same pitch can have different rhythmic patterns**.

For example, you can play Middle C in many different ways.

### Exercise A — Quarter Notes

Set metronome to **60 BPM**.

Count:

**1 2 3 4**

Play C on every number:

**C — C — C — C**

Do this for **4 measures**.

---

### Exercise B — Half Notes

Count:

**1 2 3 4**

Play C on:

**1 — 3 —**

So:

**C — — — | C — — —**

Do this for **4 measures**.

---

### Exercise C — Whole Notes

Count:

**1 2 3 4**

Play C only on **1** and hold it for four beats.

**C — — —**

Repeat for **4 measures**.

---

### Exercise D — Eighth Notes

Count:

**1 & 2 & 3 & 4 &**

Play C on every count:

**C C C C C C C C**

Do this slowly.

### Exercise E — Mix Them

Now create patterns such as:

**C — C C | C — — C**

Don't change the pitch.

Only change **when you play**.

### ✅ Success Test

You pass 3.6.1 when you can:

* Keep the same pitch.
* Change rhythms deliberately.
* Avoid accidentally speeding up.
* Keep counting continuously.

**Practice time:** 5–7 minutes.

---

# 3.6.2 — Repeated Note Timing

### 🎯 Goal

Make repeated notes **evenly spaced**.

Set:

**60 BPM**

Choose C.

Play:

**C C C C**

with each C exactly on:

**1 2 3 4**

Continue for **8 measures**.

### Step 1 — Very Slow

Play:

**C — C — C — C**

Listen to the distance between notes.

Ask yourself:

> "Is the space between every note the same?"

---

### Step 2 — Use a Metronome

Metronome:

**CLICK — CLICK — CLICK — CLICK**

Your notes:

**C — C — C — C**

The C should merge with the click.

---

### Step 3 — Increase Tempo

Try:

**60 → 70 → 80 → 90 BPM**

Don't increase the tempo merely because you can physically press the key faster.

Increase only when the spacing remains even.

### 🎧 Listening Exercise

Record yourself if possible.

Listen for:

**C...C...C..C**

This means uneven spacing.

You want:

**C...C...C...C**

### ✅ Success Test

At 80 BPM, you should be able to play **16–32 repeated notes** without noticeably changing the spacing.

**Practice time:** 5 minutes.

---

# 3.6.3 — Rushing Detection

### 🎯 Goal

Learn to recognize when you are playing **too early**.

Rushing means:

> Your notes gradually move **ahead of the beat**.

This is extremely common when beginners become excited or when a difficult passage approaches.

### Exercise

Set metronome to:

**50–60 BPM**

Count:

**1 2 3 4**

Play C on each beat.

Now deliberately make a mistake.

Play:

**C C C C**

but allow yourself to become slightly faster.

Then stop and ask:

> "Did my C happen before the click?"

---

### Better Exercise

Play 8 measures.

During the first 4 measures:

**Stay exactly with the metronome.**

During the next 4 measures:

Try intentionally rushing.

Then stop.

Try to identify the difference.

### Important

Don't train rushing for too long.

The purpose is **recognition**, not developing the bad habit.

### 🎧 What rushing sounds like

Metronome:

**CLICK ... CLICK ... CLICK ... CLICK**

Your playing:

**C C C C**

If your C begins arriving **just before each click**, you're rushing.

### Correction

Think:

> **"Wait for the beat."**

Don't push the note toward the metronome.

Let the metronome come to you.

### ✅ Success Test

You can hear the difference between:

* exactly on the beat
* slightly early
* clearly early

**Practice time:** 3–5 minutes.

---

# 3.6.4 — Dragging Detection

### 🎯 Goal

Recognize when you are playing **too late**.

Dragging is the opposite of rushing.

Your playing gradually falls **behind the beat**.

### Exercise

Set:

**50–60 BPM**

Play:

**C C C C**

with the metronome.

First play accurately.

Then deliberately make your notes slightly late.

Listen carefully.

### Compare

**Rushing:**

CLICK
C

**Dragging:**

C
CLICK

**Correct:**

C + CLICK together.

---

### Correction Exercise

Imagine that the metronome is a **train**.

Your notes must stay inside the train — not behind it.

Count:

**1 2 3 4**

and play exactly on each number.

### Advanced Exercise

Play 8 measures.

Every time you notice yourself becoming late, don't stop.

Simply return to:

**1 2 3 4**

and continue.

### ✅ Success Test

You should be able to identify whether your playing is:

**early / correct / late**

without needing someone else to tell you.

**Practice time:** 3–5 minutes.

---

# 3.6.5 — Evenness Practice

### 🎯 Goal

Develop **consistent spacing between notes**.

This is slightly different from simply playing with the metronome.

You want your fingers to become rhythmically **stable**.

### Exercise 1 — Quarter Notes

60 BPM:

**1 2 3 4**

Play:

**C C C C**

for 8 measures.

---

### Exercise 2 — Eighth Notes

Count:

**1 & 2 & 3 & 4 &**

Play:

**C C C C C C C C**

Make every note equal.

---

### Exercise 3 — Accent Removal

Initially you may naturally play:

**C C C C**

with the first note louder.

Now try:

**c c c c**

Every note should have approximately the same volume.

This teaches your hand to maintain consistent control.

---

### Exercise 4 — Longer Pattern

Play continuously:

**C C C C C C C C C C C C C C C C**

Don't stop.

Your job is to maintain:

**same spacing + same tempo + same volume**

### ✅ Success Test

If someone listens with their eyes closed, the notes should sound like they are coming from a **machine**.

That's the level of evenness we're looking for.

**Practice time:** 5–7 minutes.

---

# 3.6.6 — Start on Beat

### 🎯 Goal

Learn to begin playing **exactly with the music**.

This is extremely important for your contest.

Many beginners hear:

**1 2 3 4**

and then press the first key somewhere around **1**.

We want:

> **CLICK + NOTE simultaneously.**

---

### Exercise 1 — Four-Beat Preparation

Set metronome to **60 BPM**.

Don't play anything.

Count:

**1 2 3 4**

Then on the next **1**:

**C**

Repeat.

---

### Exercise 2 — Silent Preparation

Listen to:

**CLICK — CLICK — CLICK — CLICK**

Internally count:

**1 2 3 4**

Then enter on:

**1**

Don't physically tap the keyboard beforehand.

---

### Exercise 3 — Contest Simulation

Imagine the judge says:

> "Start."

You wait.

Metronome:

**1 2 3 4**

Then:

**C**

Repeat 10 times.

### ✅ Success Test

You should be able to start exactly on the intended beat **without hesitation**.

**Practice time:** 5 minutes.

---

# 3.6.7 — Stop on Beat

### 🎯 Goal

Learn to finish exactly where you intend.

Beginners often play the final note and then stop somewhere randomly.

We want:

> **Final note + final beat = controlled ending.**

---

### Exercise 1

Set metronome to 60 BPM.

Play:

**C C C C**

for 4 measures.

On the final beat:

**C**

Then stop.

Don't continue accidentally.

---

### Exercise 2 — Final Note

Count:

**1 2 3 4**

Play:

**C — — C**

The final C must happen exactly on **4**.

Then silence.

---

### Exercise 3 — Hold and Stop

Play a whole note:

**C — — —**

Count:

**1 2 3 4**

Release exactly after **4**.

This teaches you that **release timing is also rhythm**.

---

### 🎯 Important Contest Skill

Don't think:

> "I'm finished!"

and immediately stop.

Think:

> **"The music finishes on beat 4."**

Then execute the ending.

### ✅ Success Test

Your final note and/or release consistently happens at the intended beat.

**Practice time:** 5 minutes.

# 3.6.8 — Recover After Mistake

### 🎯 Goal

This is probably the **most important exercise for contest performance**.

You WILL make mistakes.

The goal isn't:

> "Never make a mistake."

The goal is:

> **"A mistake doesn't destroy my rhythm."**

---

## Exercise 1 — Wrong Note, Keep Going

Set:

**60 BPM**

Play:

**C C C C | C C C C**

Now intentionally play one wrong note:

**C C D C | C C C C**

But keep counting:

**1 2 3 4 | 1 2 3 4**

Do **not stop**.

---

## Exercise 2 — Miss a Note

Play:

**C C C C**

Then intentionally don't play the third note:

**C C — C**

Keep counting:

**1 2 3 4**

The silence is okay.

The important thing is that the rhythm continues.

---

## Exercise 3 — Wrong Note During a Pattern

Play:

**C C C C | D D D D**

Now intentionally play:

**C C X C | D D D D**

Immediately continue.

Don't go back and correct the X.

---

## Exercise 4 — Contest Recovery

Play a simple 8-bar pattern.

At a random moment, intentionally make a mistake.

Your rule:

### ❌ Don't stop.

### ❌ Don't restart.

### ❌ Don't look at the keyboard.

### ❌ Don't try to fix the previous note.

### ✅ Keep counting.

### ✅ Find the next beat.

### ✅ Continue normally.

This trains your **performance recovery reflex**.

Only increase the tempo when your **rhythm accuracy stays stable**.

### 🏆 Final Level-3.6 Test

When you're ready, set the metronome to **80 BPM** and perform this challenge:

1. Start exactly on beat.
2. Play 16 quarter notes.
3. Switch to 16 eighth notes.
4. Keep the spacing even.
5. Intentionally play one wrong pitch.
6. Continue without stopping.
7. Finish exactly on the intended beat.
8. Stop cleanly.

If you can do that comfortably, you've developed a **real rhythm-control foundation**, not just the ability to follow a metronome.
