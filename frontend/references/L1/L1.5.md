# 1.5.1 — 🎹 Random White Note

### Goal

Instantly recognize:

**C D E F G A B**

without thinking about the entire keyboard.

### How to practice

Start with a small section around middle C.

Generate a random note:

> `E`

Your job:

> **E → visually locate E → touch it**

Then:

> `C → touch C`

Then:

> `A → touch A`

etc.

### Important rule

Don't say:

> "C... let me find the two black keys..."

That is still a **search algorithm**.

At this stage, you're beginning to build:

> **C → visual location**

### Session

Do:

* 2 minutes
* random C–B
* one note at a time
* touch the key
* don't play it yet
* don't count keys

### Target

Initially:

> **~1–2 sec/note**

Eventually:

> **< 0.5 sec/note**

Don't worry about speed initially. **Accuracy first.**

> **Bb → A#/Bb key**

```text
Bb
```

### Target

Eventually:

> `Gb` → key

should be just as natural as:

> `F#` → key

Now we make the brain-hand connection explicit.

This is different from simply recognizing notes.

# 1.5.7 — 🔄 Key → Note Drill

Now reverse the direction.

This is VERY important.

Instead of:

> **C → key**

> **key → name**

### Exercise

> **C# / Db**

> **F**

> **A#/Bb**

> **G**

### Why this matters

You're building the reverse mapping:

```text

```


```text

```

This makes the keyboard feel like a **map in your brain**, rather than something you're visually searching.

> **50 random keys**

# 🧠 One VERY important distinction

Buddy, don't confuse **recognition speed** with **hand movement speed**.

Right now we're primarily training:

> **"Where is this note?"**

not:

> **"How fast can my finger physically move?"**

For example:

```text
Random input: G#

Brain:
"G# → that black key"

Hand:
moves there
```

That first reaction is what we're trying to make automatic.

Once that becomes automatic, **speed naturally becomes much easier**.

And because you're already working through the C→B and reverse-sequence drills, **1.5.8 + 1.5.9 are going to be especially important for you**. Your recent experience of getting confused when random descending sequences became difficult is actually useful feedback: it means the **sequential mapping is developing, but random-access mapping isn't automatic yet**.

So don't interpret a bad random run as failure. It's exactly the weakness this bucket is designed to expose. 💪🎹
