# 🎼 LEVEL 6 — MUSIC READING

## 🎹 Bucket 6.7 — Notation → Keyboard

### 🎯 Overall Contest Goal

By the end of this bucket, when you see a note such as:

**Treble:** `C4` → immediately think **Middle C** → find the key → play it.

Or:

**Bass:** `F3` → immediately identify the note → locate the lower F → play it.

And eventually:

**♯ / ♭ + note** → recognize the altered pitch → find the correct black/white key → play it.

---

# 🟦 6.7.1 — Note → Key

### 🎯 Objective

Build the fundamental connection:

**Staff position → Note name → Keyboard key**

### What you practice

Start with **single notes only**.

For example:

**Treble clef**

* Middle C
* D
* E
* F
* G
* A
* B
* C

Then gradually expand upward.

**Bass clef**

* C
* D
* E
* F
* G
* A
* B
* etc.

### Practice Method

For every note:

1. 👀 Look at the note.
2. 🗣️ Say its name aloud.
3. 🧠 Think about its keyboard location.
4. 👆 Find the key.
5. 🎹 Play it once.
6. 🔁 Repeat.

Example:

> See note → “E” → find E → play E.

### Beginner Drill

Do **20 notes**.

Don't worry about speed initially.

Your target:

**20/20 correct.**

### Progression

**Stage 1:** Note → say
**Stage 2:** Note → say → find
**Stage 3:** Note → say → find → play
**Stage 4:** Note → find → play

That final stage is important because eventually you don't want to spend unnecessary time verbally analyzing every note.

---

# 🟦 6.7.2 — Treble → Keyboard

### 🎯 Objective

Become comfortable converting **Treble Clef → Keyboard**.

This is especially important for your right-hand/upper-register reading.

### Start with

Learn the landmark notes first:

* Middle C
* D
* E
* F
* G
* A
* B
* High C
* High D
* High E

### Practice

Take one treble note.

Example:

**Treble E**

Think:

> Staff position → E → keyboard E → PLAY

Then another.

### Drill

Do **30 treble notes**.

Mix:

* line notes
* space notes
* ledger notes

Initially keep the notes within a comfortable range.

### Important Rule

Don't always start counting from Middle C.

Instead, develop **landmarks**.

For example:

> “That's G.”

rather than:

> “Middle C... D... E... F... G...”

That counting method becomes too slow for a contest.

### Speed Target

Eventually:

**See note → identify → play within 1–2 seconds.**

---

# 🟦 6.7.3 — Bass → Keyboard

### 🎯 Objective

Build the same connection for the **Bass Clef**.

This prevents the common beginner problem:

> “I can read treble, but bass notes take forever.”

### Practice Range

Start around:

**C2 → C4**

Then expand.

### Drill

For each note:

**See → Name → Find → Play**

Example:

> Bass F → “F” → locate lower F → play.

### Important

Practice bass **separately** at first.

Don't immediately mix treble and bass.

You want your brain to become comfortable with:

**Bass notation = actual keyboard location**

### Drill

**25–30 bass notes**

Aim for:

**90%+ accuracy**

before increasing speed.

---

# 🟦 6.7.4 — Accidentals → Keyboard

### 🎯 Objective

Convert:

**Note + ♯ / ♭ → Correct keyboard key**

This connects directly with your **Bucket 6.5 Accidentals** work.

### Example

If you see:

**F♯**

Your brain should immediately understand:

> F → raise by one semitone → F♯ → black key between F and G.

Similarly:

**B♭**

> B → lower by one semitone → B♭ → black key between A and B.

### Practice Levels

#### Level A — Natural vs Sharp

Mix:

* C
* C♯
* D
* D♯
* E
* F
* F♯

etc.

#### Level B — Natural vs Flat

Mix:

* D
* D♭
* E
* E♭
* G
* G♭

etc.

#### Level C — Mixed

Mix:

**♯ + ♭ + ♮**

### Important Drill

Don't merely say:

> “F sharp.”

Also physically locate it.

**See → Say → Find → Play**

### Special attention

Practice enharmonic situations later:

**F♯ = G♭**

because they represent the same keyboard key but can appear differently in notation.

# 🟦 6.7.5 — Note Distance

### 🎯 Objective

Stop seeing notes as isolated objects.

Instead begin seeing:

> **How far did the music move?**

For example:

**C → D**

= small movement.

**C → E**

= larger movement.

**C → G**

= much larger movement.

### Practice

Look at two notes.

Ask:

> “How far apart are they?”

Start with:

* same note
* step
* skip
* larger interval

### Example

**C → D**

Think:

> Up one note letter.

**C → E**

Think:

> Up two note letters.

### Keyboard Connection

Then physically play both.

**See → Understand distance → Find → Play**

### Why this matters

Eventually you don't want to process every note independently.

You want your brain to recognize:

> “We're moving upward by a step.”

That dramatically improves reading speed.

---

# 🟦 6.7.6 — Stepwise Motion

### 🎯 Objective

Recognize notes moving **one letter at a time**.

Examples:

**C → D → E → F → G**

or downward:

**G → F → E → D → C**

### Practice

Read short sequences.

Example:

> C → D → E → F

Instead of thinking:

> C... find C
> D... find D
> E... find E
> F... find F

start thinking:

> C → up → up → up

### Keyboard Practice

Play the sequence smoothly.

Focus on:

**Reading + movement**

rather than individual note memorization.

### Drill

Do:

* 5 ascending patterns
* 5 descending patterns
* 5 mixed patterns

Example:

**C-D-E-F**

**G-F-E-D**

**E-F-G-A**

**A-G-F-E**

### Goal

Your eyes should begin seeing **direction** automatically.

---

# 🟦 6.7.7 — Skips

### 🎯 Objective

Recognize notes that move by **skipping over one letter name**.

Example:

**C → E**

There is D between them.

**E → G**

F is between them.

### Visual Concept

Step:

**C → D**

Skip:

**C → E**

Larger skip:

**C → F**

### Practice

First identify:

> Step or Skip?

Then:

> What note?

Then:

> Find it on keyboard.

### Drill

Mix:

* C → D
* C → E
* E → F
* E → G
* G → A
* G → B

### Important

Don't only practice naming.

Look at the **visual shape on the staff**.

Eventually your brain should recognize:

> “These two notes have a space between them.”

and immediately associate that with a larger keyboard movement.

---

# 🟦 6.7.8 — Repeated Notes

### 🎯 Objective

Recognize when the same pitch appears repeatedly.

Example:

**C → C → C → C**

Your brain should not waste time re-identifying it each time.

### Practice

Start with:

**C C C C**

Then:

**C C D D**

Then:

**C C E C**

Then longer patterns.

### Keyboard Drill

Example:

**C C C D E E E**

Play while keeping your eyes on the notation.

### Important Skill

Train yourself to recognize:

> **Same visual position = same pitch**

This improves reading stability and prevents unnecessary searching.

### Drill

Practice:

* 5 repeated-note patterns
* 5 mixed repeated-note patterns
* 5 short melodic patterns

---
