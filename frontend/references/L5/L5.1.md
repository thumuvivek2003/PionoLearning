# 🟢 5.1.1 — What Is a Chord?

### Concept

A **single note** is one sound.

A **chord** is multiple notes played together.

For now, your focus is on **three-note chords**, called **triads**.

### 🎹 Keyboard Practice

Start with:

**C**

Play only C.

Then play:

**C + E**

Then:

**C + E + G**

Listen to the difference.

Now repeat:

* D
* D + F
* D + F + A
* E
* E + G
* E + G + B

### Practice Drill

Play:

**1 note → 2 notes → 3 notes**

For 5 different roots.

Don't worry about major/minor yet.

### 🎯 You should be able to answer

> What is a chord?

**Multiple notes sounding together.**

---

# 🟢 5.1.2 — Triad Concept

A **triad = 3 notes**.

The basic triad structure uses:

**1st + 3rd + 5th notes**

For example, using the C major scale:

**C D E F G A B**

Take:

* 1 = C
* 3 = E
* 5 = G

Therefore:

**C-E-G = C Major Triad**

### 🎹 Practice

Build triads from these roots:

| Root | 1 | 3  | 5 |
| ---- | - | -- | - |
| C    | C | E  | G |
| D    | D | F♯ | A |
| E    | E | G♯ | B |
| F    | F | A  | C |
| G    | G | B  | D |

Play each slowly.

### Important

Don't memorize the individual chords yet.

Start thinking:

> **Root → 3rd → 5th**

### 🎯 Goal

You should understand:

**3 notes = triad**

and begin seeing chords as **patterns**, not random collections of notes.

# 🟢 5.1.5 — Minor Triad Formula

Now change just **one note**.

## Major:

**1 - 3 - 5**

## Minor:

**1 - ♭3 - 5**

The **3rd comes down by one semitone**.

Example:

### C Major

**C-E-G**

Lower E by one semitone:

**E → E♭**

Therefore:

### C Minor

**C-E♭-G**

---

### 🎹 Compare

Play:

**C-E-G**

Then:

**C-E♭-G**

Listen carefully.

The **only difference is the 3rd**.

---

### Practice

Build:

* C minor
* D minor
* E minor
* F minor
* G minor
* A minor
* B minor

For every chord, say:

> **1 - ♭3 - 5**

### 🎯 Goal

Your brain should automatically recognize:

**Major → normal 3rd**

**Minor → lowered 3rd**

# 🟢 5.1.8 — Triad Recognition

Now reverse the process.

Instead of:

> Root → Build chord

> **Chord → Identify it**

This is extremely important.

---

## 🎹 Exercise 1 — Identify the Root

Play:

**C-E-G**

> What chord is this?

**C Major**

Play:

**D-F-A**

→ **D Minor**

**G-B-D**

---

## 🎹 Exercise 2 — Identify Major/Minor

Play a random triad.

Ask:

1. What is the root?
2. Is it major or minor?
3. What is the formula?

For example:

**A-C-E**

Root = **A**

3rd = **C**

5th = **E**

Therefore:

**A Minor**

Formula:

**1-♭3-5**

# 🧠 Your Mental Model

Don't try to memorize 24 chords separately.

Think like this:

```text
                 TRIAD
                   │
          ┌────────┴────────┐
          │                 │
       MAJOR              MINOR
          │                 │
       1-3-5             1-♭3-5
          │                 │
    normal 3rd          lowered 3rd
          │                 │
       C-E-G             C-E♭-G
```

The **3rd is the key**.

```text
1 - 3 - 5      = MAJOR
1 - ♭3 - 5     = MINOR
```
