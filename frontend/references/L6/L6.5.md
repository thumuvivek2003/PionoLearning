# 6.5.1 — Sharp ♯

### 🎯 Concept

A **sharp raises a note by one semitone**.

Think:

**♯ = move one key to the right/up by 1 semitone**

For example:

**C → C♯**

On the keyboard:

**C → C♯**

You move **one semitone upward**.

### 🎹 Important examples

| Natural | Sharp | Result    |
| ------- | ----- | --------- |
| C       | C♯    | black key |
| D       | D♯    | black key |
| E       | E♯    | **F**     |
| F       | F♯    | black key |
| G       | G♯    | black key |
| A       | A♯    | black key |
| B       | B♯    | **C**     |

Notice something very important:

**E♯ is F**

and

**B♯ is C**

There isn't a black key between E–F or B–C.

### 🧠 Practice

Start with natural notes.

Say:

> C → C♯
> D → D♯
> F → F♯
> G → G♯
> A → A♯

Then play them.

After that, practice the tricky ones:

> E → E♯ = F
> B → B♯ = C

### 🎯 Your target

When you see:

**F♯**

you shouldn't think:

> "What does sharp mean again?"

You should immediately think:

> **F + one semitone = F♯**

---

# 6.5.2 — Flat ♭

### 🎯 Concept

A **flat lowers a note by one semitone**.

Think:

**♭ = move one key to the left/down by 1 semitone**

For example:

**D → D♭**

You move one semitone downward.

### 🎹 Important examples

| Natural | Flat | Result    |
| ------- | ---- | --------- |
| C       | C♭   | **B**     |
| D       | D♭   | black key |
| E       | E♭   | black key |
| F       | F♭   | **E**     |
| G       | G♭   | black key |
| A       | A♭   | black key |
| B       | B♭   | black key |

Again, two important cases:

**C♭ = B**

**F♭ = E**

### 🧠 Practice

Say and play:

> D → D♭
> E → E♭
> G → G♭
> A → A♭
> B → B♭

Then practice:

> C → C♭ = B
> F → F♭ = E

### 🎯 Your target

When you see:

**G♭**

your brain should immediately think:

> **G down one semitone = G♭**

# 6.5.3 — Natural ♮

This one needs a little more explanation, buddy.

### 🎯 What does ♮ actually do?

A **natural cancels a previous sharp or flat** affecting that note.

For example:

**F♯ → F♮**

The ♮ tells you:

> "Don't play F♯ anymore. Play normal F."

Similarly:

**B♭ → B♮**

means:

> "Cancel the flat. Play normal B."

### ⚠️ Important correction to your core understanding

You wrote:

> ♮ = return to natural

That's a good beginner idea, but more precisely:

**♮ = cancel the sharp/flat and return that note to its natural pitch.**

### 🎹 Practice

Play:

**C → C♯ → C♮**

Then:

**D → D♭ → D♮**

Then:

**F → F♯ → F♮**

Then:

**B → B♭ → B♮**

### 🧠 Mental exercise

I'll give you:

**G♯ → G♮**

You should think:

> G♯ → cancel sharp → G

Another:

**E♭ → E♮**

Think:

> E♭ → cancel flat → E

# 6.5.6 — Accidental on Staff

Now we move from **keyboard understanding → actual music reading**.

You will start seeing an accidental directly beside a written note.

For example:

**♯ + note**

means:

> Raise this note by one semitone.

**♭ + note**

means:

> Lower this note by one semitone.

**♮ + note**

means:

> Cancel the previous alteration.

### 🎼 Your reading process

Whenever you see a note with an accidental, use this sequence:

### Step 1 — Identify the note

For example:

**F**

### Step 2 — Identify the accidental

Suppose you see:

**♯**

### Step 3 — Apply the accidental

**F + one semitone = F♯**

### Step 4 — Find it on keyboard

Locate:

**F♯**

### Step 5 — Play it

This five-step process is exactly what we want to train.

# 6.5.7 — Accidental → Keyboard

This is probably the **most important practice session in this bucket**, buddy.

Here we stop treating music notation and keyboard geography as two separate things.

We connect them.

### 🎯 Your mental pipeline

You should eventually develop:

**Staff → Note → Accidental → Pitch → Keyboard key**

For example:

**F + ♯**

↓

**F♯**

↓

**one semitone above F**

↓

**black key between F and G**

↓

🎹 **play F♯**

### Practice Round 1 — Easy

Take:

> C♯
> D♯
> F♯
> G♯
> A♯

For each one:

1. Say the note.
2. Say what the accidental does.
3. Find the key.
4. Play it.

### Practice Round 2 — Flats

> D♭
> E♭
> G♭
> A♭
> B♭

Same process.

### Practice Round 3 — Tricky ones

> E♯
> B♯
> C♭
> F♭

Your answers should be:

**E♯ = F**

**B♯ = C**

**C♭ = B**

**F♭ = E**

These are excellent exercises because they prevent you from assuming:

> "Sharp = black key"

or

> "Flat = black key."

That's **not always true**.

# 🧠 One VERY important concept: Enharmonic notes

You will eventually encounter things like:

**C♯ = D♭**

They are **the same piano key** in standard equal temperament.

Likewise:

**D♯ = E♭**

**F♯ = G♭**

**G♯ = A♭**

**A♯ = B♭**
